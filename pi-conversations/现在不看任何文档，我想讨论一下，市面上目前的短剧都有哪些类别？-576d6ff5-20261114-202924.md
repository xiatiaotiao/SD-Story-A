市面上目前的短剧，主要可以从两个维度来看：**一是产品形态（怎么播、怎么看），二是受众与题材赛道（给谁看、卖什么情绪）**。

在实际创作和商业投流中，行业最核心的分类逻辑是**受众性别与核心情绪**，主要分为男频、女频，以及近一年快速爆发的银发（中老年）盘和精品横屏盘。

---

### 一、产品形态分类

1. **竖屏微短剧（小程序剧 / 平台信息流剧）**
   - **规格**：单集1-2分钟，整部80-120集左右。
   - **特点**：竖屏拍摄，专为手机单手操作设计；前几集强冲突抓人，中后段每集结尾卡在冲突悬念最高点（钩子），靠付费充值或看广告解锁。
2. **中视频短剧 / 横屏精品短剧（长视频平台短剧）**
   - **规格**：单集10-20分钟，整部12-24集。主要在腾讯视频、芒果TV、优酷、爱奇艺等长视频平台播放。
   - **特点**：横屏制作，视听和叙事更接近传统网剧的精简版，制作成本较高，重在剧情连贯性和人物质感，靠分账和会员收益。
3. **短视频账号短剧（抖音、快手达人剧）**
   - **规格**：单集2-5分钟，十几集到几十集不等。
   - **特点**：围绕达人人设打造，主要目的是涨粉、品牌商业植入或为直播带货做铺垫。

---

### 二、按受众与核心情绪划分的题材类别

短剧的本质是“情绪消费”。观众看什么类别，取决于他们想在几分钟里宣泄什么情绪。

#### 1. 男频赛道（核心情绪：憋屈后的尊严翻盘、掌控一切的掌控欲、打脸欺负自己的人）
- **战神 / 兵王 / 龙王归来**：男主本是顶天立地的军神或神秘势力首领，因承诺或低调退隐，在底层生活被恶霸、亲戚百般羞辱，关键时刻亮明身份，各大名流齐齐跪拜，直接反转打脸。
- **赘婿翻盘 / 隐藏首富**：上门女婿在岳母家做牛做马、受尽白眼，妻子也对他失望。男主实际是隐形万亿集团继承人，或者是完成三年考验期解封资产，一朝翻身成为所有人的金主。
- **都市神医 / 鉴宝异能**：底层小人物意外获得祖传医术、透视眼或特殊技能。靠一眼断玉、起死回生在名流阶层平步青云，惩治庸医与恶少。
- **重生搞钱（时代红利）**：主角带着几十年的先知记忆，重生回十几或几十年前（如80/90年代、千禧年）。抢先拿下暴利风口、弥补前世对母亲或妻子的遗憾，走上商业巅峰。
- **末世安全屋 / 系统升级**：近期热度上升的硬核题材。极寒、极热或末世降临，主角提前囤积物资、加固避难所，冷眼旁观前世背叛他的亲朋邻里，靠绝对实力碾压敌人。

#### 2. 女频赛道（核心情绪：被绝对偏爱的安全感、情感复仇、阶层跨越、尊严认可）
- **霸总 / 闪婚强宠**：普通女孩（实习生、打工人、替嫁女）遭遇家庭困境，意外与千亿总裁闪婚或签下契约婚姻。男主对外杀伐果断、冷血无情，对女主暗中护短、无底线偏爱，先婚后爱。
- **真假千金 / 豪门认亲**：从小在乡下受苦的真千金被接回豪门，心机假千金处处陷害、父母偏心。真千金靠自己的真实本事（或者暗藏的顶级身份）逐一揭穿假千金的阴谋，重获尊重或决绝离开。
- **带球跑 / 萌宝助攻**：男女主当年因为阴差阳错或误会分开，女主怀着孩子远走他乡。数年后女主带着高智商天才萌宝回国，萌宝主动帮爹妈牵线，一边收拾恶毒女配，一边解开当年误会。
- **手撕渣男 / 绝情复仇 / 断亲**：全职太太或忠心妻子遭遇渣男出轨、婆家算计。女主不再忍气吞声，暗中搜集证据，在关键场合让渣男身败名裂、净身出户，并迅速与更优秀的男人联手。
- **多重马甲女强**：女主表面看起来柔弱可欺、无依无靠，暗地里却是世界顶尖黑客、神秘神医、王牌设计师。反派每想打压她一次，她就掉一层马甲，狠狠打脸对手。
- **古装宫斗 / 宅斗重生**：女主前世被夫君和恶毒姐妹背叛惨死，重生回闺阁待嫁之时。步步为营，借力打力，铲除恶毒亲眷，嫁给权倾朝野的王爷或皇帝。

#### 3. 中老年 / 银发赛道（近一年爆发力最强的蓝海增量）
- **老霸总 / 夕阳红闪婚**：隐瞒身份的退休老董事长，去社区相亲或在公园偶遇勤劳善良的保洁阿姨，两人走到一起。儿女嫌贫爱富百般刁难，最后发现老头就是家族企业的幕后掌控者。
- **苦情与孝道纠葛**：农村苦熬一生的母亲进城投奔儿女，被不孝的儿子、儿媳嫌弃羞辱，母亲默默承受；最终儿女遭遇重大危机，全靠母亲藏了一辈子的积蓄、人脉或恩情挽救，儿女跪求原谅。核心是切中中老年群体对子女付出的委屈与渴望被尊重的心态。

#### 4. 精品与创新跨界赛道（以横屏、短视频平台精品剧为主）
- **微型悬疑 / 密室逃生**：主打高智商博弈、时间循环、连环反转。不依赖狗血冲突，靠逻辑严密的情节和压迫感留住观众。
- **反内卷 / 职场发疯轻喜**：解构传统职场压榨和家庭道德绑架，主角不讲传统礼貌，有仇当场报、谁惹我我怼谁，给年轻打工人提供解压情绪。
