# 单元案备选（职场专题）

本文件专门收录针对年轻观众群体、契合现代打工人真实生存痛点的职场类单元案件。各个案件均设计了强烈的现实共鸣、极高的败诉赌注，以及由沈明非（陆鸣）凭借顶尖律师经验打出的反直觉法律破局手段。

---

## 案件一：职场垄断与竞业霸凌（《天价自由》）

### 1. 📌 案件基本信息
* **案件定性**：劳动争议与民事侵权交叉
* **原告/委托人**：赵晴（25岁，工作3年的初级UI设计师，月薪8000元）
* **被告方**：前东家（中型科技互联网公司）

### 2. 普遍共鸣与遭遇（为什么让人同情）
* 赵晴在入职时被要求签署全员标准版《竞业限制协议》。离职后，公司每月仅向其发放1200元竞业限制补偿金，却在竞品排除清单中将业内几乎所有的软件、设计外包及互联网公司全部列入，导致赵晴离职后失业四个月，生计断绝。
* 为维持生活，赵晴在正规自由职业接单平台上接了一笔3000元的零工插画单。
* 派单方实际上是前东家HR与法务联合外部商业调查公司设下的钓鱼陷阱。前东家通过全程录像、公证转账记录，以赵晴“违反竞业限制协议、向竞争对手提供核心智力服务”为由提起仲裁并起诉，索赔**60万元天价惩罚性违约金**，并在行业社群发布背调通报。

### 3. 败诉的严重后果（赌注）
* 若赵晴败诉，法院将判定其承担60万元巨额违约金。对于毫无积蓄的年轻打工人而言，个人银行账户及微信零钱将被依法冻结，名下代步电动车被查封，赵晴直接沦为失信被执行人。
* 在整个设计行业背负“拿补偿金私接竞品、背叛老东家”的行业恶名，青年职业生涯就此终结。

### 4. 奇葩/反直觉的诉求（破局切口）
沈明非代理赵晴后，放弃常规的“辩解所接外包不属于竞品”的被动思路，直接发起反向诉讼与程序绝杀：
1. **主张竞业限制协议自始无效**：依据《劳动合同法》第二十四条，竞业限制的人员限于高级管理人员、高级技术人员和其他负有保密义务的人员。调取公司底层权限日志，证明赵晴在职期间仅具有基层绘图权限，从未接触过核心技术秘密与算法架构，用人单位属于滥用优势地位、以格式条款变相剥夺劳动者生存权。
2. **启动非法证据排除**：将派单的皮包公司与前东家法务主管之间的亲属关联、资金往来记录公之于众，证明该证据链完全由用人单位主观恶意诱发，属于非法诱导侵害，依法排除视听证据。
3. **反诉恶意诉讼与名誉侵权**：以《反不正当竞争法》与《民法典》名誉权条款反诉前东家，要求前公司就全行业通报道歉，并赔偿商誉损害抚慰金20万元。

## 案件二：数字极权与工时盗窃（《隐形监控器》）

### 1. 📌 案件基本信息
* **案件定性**：侵害个人信息权益、名誉权与劳动报酬纠纷
* **原告/委托人**：张建国（34岁，电商公司资深文案策划，上有患重病母亲）
* **被告方**：前雇主（知名电商品牌公司）及监控软件技术供应商

### 2. 普遍共鸣与遭遇（为什么让人同情）
* 张建国的母亲突发脑溢血住院。在陪护期间，张建国白日在医院看护，夜间在病床旁通宵达旦工作，如期交付了当季核心电商大促全套文案，带动公司单月销售额创历史新高。
* 大促结束后，公司为规避合同约定的15万元年终业绩奖金，从张建国的工作笔记本中调取后台“AI工效监控系统”数据。公司宣称张建国“上班期间键盘鼠标静止率达40%，面部多次离开摄像头识别区，属于严重欺诈工时与旷工”。
* 公司不仅单方违法开除张建国、扣发全额奖金，还以“以虚假出勤骗取薪资造成管理损失”为由反诉张建国返还20万元薪酬。

### 3. 败诉的严重后果（赌注）
* 张建国母亲后续康复与手术费用彻底断供。
* 个人档案被记上“以欺诈手段骗取薪资被开除”的严重违纪通报，同城业内背景调查全线飘红，无法再被正规企业录用。

### 4. 奇葩/反直觉的诉求（破局切口）
沈明非代理张建国后，以《个人信息保护法》为核心武器实施反制：
1. **起诉非法监控与生活隐私侵权**：监控软件在未取得员工本人及病房其他第三人单独书面同意的情况下，24小时自动抓拍私人生活画面与病历隐私。沈明非起诉雇主与软件开发商共同侵权，主张全案监控数据属于违法取得，依法不得作为定案证据。
2. **确立脑力劳动实质成果验收标准**：提交大促上线方案的时间戳、客户好评记录、全网爆款转化数据，证明脑力创作者的核心价值在于最终成果交付，击碎“以鼠标点击频率衡量智力劳动”的伪科学算法。
3. **追讨顶格薪酬与精神抚慰金**：判令用人单位全额补发15万元绩效奖金，并连带软件商就侵入私人生活安宁赔偿精神抚慰金。

## 案件三：冷暴力逼退与工位禁闭（《被抹去的人》）

### 1. 📌 案件基本信息
* **案件定性**：人格尊严侵权、健康权纠纷与劳动关系解除
* **原告/委托人**：林芳（32岁，入职5年的业务骨干）
* **被告方**：用人单位及空降业务总监个人（列为共同被告）

### 2. 普遍共鸣与遭遇（为什么让人同情）
* 公司为逃避法定裁员赔偿金，由新任空降总监推行“隐形逼退计划”。林芳因拒绝签署“自愿降薪40%”的无理协议，遭遇长达数月的系统性冷暴力。
* 林芳被移出全部工作群组，注销内网业务权限，工位被单独搬迁至阴暗无窗、堆放废弃纸箱与电缆的配电间外通道。总监每天指派其唯一的工作是“纯手工手抄公司守则一万字，并在晨会上公开朗读反思”。
* 在全员孤立与当众羞辱下，林芳罹患重度抑郁症并引发自残。

### 3. 败诉的严重后果（赌注）
* 林芳付出5年心血却一分钱补偿拿不到；因重度抑郁症长期无法工作，医疗支出耗尽家庭积蓄，个人尊严被彻底碾碎。

### 4. 奇葩/反直觉的诉求（破局切口）
沈明非不走常规劳动仲裁流程，直接以民事侵权与惩罚性措施立案：
1. **穿透法人面纱，起诉总监个人侵权**：依据《民法典》第一千零九条（自然人的人格尊严受法律保护），将实施冷暴力的总监个人列为共同被告，要求其以个人财产承担侵权责任，杜绝施暴者躲在公司制度背后免责。
2. **提出公开道歉硬性执行诉求**：判令总监个人在公司官方公众号、内部全体邮件及早会现场，连续30天公开发布并当众宣读亲笔书写的道歉信。
3. **查获假账线索实施反向施压**：沈明非获取该总监利用逼退老员工节省下来的预算向母公司虚报套取“降本增效奖金”的内部证据，在庭审现场当面指出其涉嫌职务侵占，逼迫公司撤换总监并支付法定最高赔偿。

## 案件四：财务替罪羊与虚假诉讼（《空白签字单》）

### 1. 📌 案件基本信息
* **案件定性**：涉刑民交叉（职务侵占自诉/经侦报案反制与虚假诉讼）
* **原告/委托人**：周晓蒙（24岁，刚入职2年的普通女出纳，月薪5500元）
* **被告方**：前公司法定代表人兼实际控制人

### 2. 普遍共鸣与遭遇（为什么让人同情）
* 周晓蒙在职期间，老板以“公司走对公流程太慢、为避税和应急垫付供应商费用”为由，长期通过微信语音和零散便条，指令周晓蒙使用个人微信及银行卡代收货款并转账垫付。
* 后来公司因违规投资面临巨额债务清算，老板企图卷款跑路并将窟窿转嫁给基层人员。老板凭借周晓蒙此前签字的多份空白收支对账单，以及欠缺正规发票的报销凭单，向公安经侦报案指控周晓蒙“利用职务便利，侵占公司资金85万元”，同时向法院提起全额民事清偿诉讼。
* 周晓蒙父母收到传票与经侦约谈通知后几近崩溃，准备卖掉县城老家唯一住房代女还债。

### 3. 败诉的严重后果（赌注）
* 若定性为职务侵占罪且数额巨大，周晓蒙将面临5年以上有期徒刑；
* 人生背负刑事犯罪案底，家庭资产全数赔光，终身陷入极度贫困。

### 4. 奇葩/反直觉的诉求（破局切口）
沈明非利用前世高级合伙人的刑辩穿透视野，完成全案反打：
1. **资金流向终极穿透**：向司法机关申请调取完整的资金穿透流水，精确证实流经周晓蒙私人账户的85万元，均在数小时内经多道中间壳账户，最终全部回流至老板情妇控制的地下私募基金，周晓蒙分文未取。
2. **电子取证恢复指令链条**：通过司法鉴定中心提取并恢复老板在微信中撤回及单向删除的语音指令，形成完整的“机械职务执行证明”，推翻其非法占有主观故意。
3. **反戈一击，当庭移送犯罪线索**：沈明非在听证程序中出示老板利用员工账户洗钱、伪造空白单据虚增债务以及虚开发票数千万的证据链，直接请求法庭中止审理并将犯罪线索移送公安机关，以“诬告陷害罪”与“虚假诉讼罪”依法追究老板刑事责任。
